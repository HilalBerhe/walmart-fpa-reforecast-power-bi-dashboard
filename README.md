# Walmart FY2027 FP&A Reforecast & Power BI Dashboard

## Project Overview

This project is a Power BI dashboard built from my previously completed **Walmart Quarterly FP&A Reporting Dashboard & Reforecast Model**, which is also posted on my GitHub.

The goal of this project was to take the outputs from the original Excel-based FP&A model and turn them into a clean executive-style Power BI dashboard. The dashboard compares Walmart’s FY2027 budget against the updated reforecast, highlights favorable and unfavorable variances, and summarizes key financial performance indicators across revenue, profitability, margins, free cash flow, and tax performance.

## Data Source

The data used in this Power BI dashboard comes from my previously completed **Walmart Quarterly FP&A Reporting Dashboard & Reforecast Model**, which is also posted on my GitHub.

The original Excel model included FY2027 budget assumptions, quarterly reforecast outputs, KPI dashboard calculations, budget variance analysis, historical financial data, and supporting assumptions.

For this Power BI project, I created a clean KPI source sheet from the model outputs so the key budget, reforecast, variance, margin, and status metrics could be visualized clearly in Power BI.

This dashboard is an extension of the original Excel-based FP&A model. The Excel model handled the financial modeling and reforecast calculations, while Power BI was used to present the final KPI insights in a more visual executive dashboard format.

## Key Insights

FY2027 reforecast revenue is below budget, mainly driven by lower net sales. Total revenue came in below budget by approximately **$19.3 billion**, while net sales were below budget by approximately **$20.7 billion**.

Despite weaker revenue performance, operating income and net income were favorable versus budget. This suggests that stronger margin performance and a lower effective tax rate helped offset the top-line shortfall.

Free cash flow was the largest unfavorable variance, coming in approximately **$6.6 billion** below budget. This indicates that cash flow performance remains the biggest area of concern in the FY2027 reforecast.

Overall, the reforecast shows weaker revenue and cash flow performance, but stronger profitability quality due to margin improvement and tax rate benefits.
